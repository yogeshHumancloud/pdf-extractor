**Features:**

### 📊 CSV (.csv)
**Best for:**
- Excel/Google Sheets
- Data analysis
- Database import
- Bulk processing

**Features:**
- Standard CSV format
- Properly escaped quotes
- Header row
- Found/Not Found column

**Open with:**
- Microsoft Excel

- Any spreadsheet app

### 📋 JSON (.json)
**Best for:**
- Programming/APIs

- Backend integration
- Data transformation

- Error information

**Open with:**
- Code editors
- JSON viewers

- Programming languages
