# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2025-12-15

### Added
- Initial release of @yogeshvitekar/pdf-reader
- Text extraction from PDF documents
- Automatic table detection and extraction
- Support for multiple page processing
- PDF metadata extraction (title, author, dates, etc.)
- Table export to CSV and JSON formats
- Region-based text extraction
- Text statistics (word count, fonts, etc.)
- Progress tracking for long PDFs
- Built with latest PDF.js 5.4.449
- Comprehensive API documentation
- React usage examples
- Browser UMD support
- TypeScript-ready structure

### Features
- Frontend-only processing (no backend required)
- Modern ES6+ codebase with Babel transpilation
- Webpack bundling for production
- UMD module format for universal compatibility
- Detailed element positioning data
- Font information extraction
- Viewport dimensions

### Developer Experience
- Complete documentation with examples
- Test HTML file included
- .gitignore configured
- MIT License
- Clean project structure
